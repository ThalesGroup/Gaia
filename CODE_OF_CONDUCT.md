# Code of Conduct

## Our Standards

We are committed to a respectful, inclusive, and harassment-free community.

Examples of expected behavior:

- be respectful and constructive
- welcome different viewpoints
- accept feedback gracefully
- focus on what is best for the project

Unacceptable behavior includes:

- harassment, insults, or discrimination
- personal attacks or trolling
- publishing private information without consent

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests,
discussions, and other official communication channels.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues,
and other contributions that violate this Code of Conduct.
